# 臺北市各行政區人口與戶數 BI Demo

用 AI（Claude Code）把臺北市公開的人口統計報表，做成可以互動篩選的 BI 網頁，並用 GitHub Pages 對外發佈。

- 資料年度：民國 115 年（西元 2026 年）。
- 資料範圍：目前原始檔有數值的月份為 1–9 月。
- 地理範圍：臺北市 12 個行政區。
- 資料內容：各行政區戶數、總人口數、男性人口數、女性人口數，以及里數、鄰數。
- 原始資料：`115年1-12月各區人口數.ods`。
- 分析目的：觀察臺北市各行政區的人口規模、男女比例、戶數與每月人口變化。

## 製作流程

| 階段 | 內容 |
|---|---|
| P0：開始 | 用 template 建立自己的 GitHub repo，啟動 Claude Code |
| P1：ETL | 將 ODS 各月份報表轉成標準 CSV，並驗證資料 |
| P2：做出 BI 網頁 | 建立可依月份、行政區篩選的互動圖表 |
| P3：發佈 | Push 到 GitHub，開啟 GitHub Pages |

## 預計目錄

```text
臺北市人口統計資料/
  115年1-12月各區人口數.ods    原始報表，保留不修改

  validate.py                 資料驗證程式
prompts/                      各階段使用的 AI 指令

```

## 資料欄位

**data/population.csv**（每列：年月 × 行政區）

| 欄位 | 說明 |
|---|---|
| year | 西元年，例如 `2026` |
| month | 月份，例如 `1` |
| district | 行政區，例如松山區、大安區 |
| households | 戶數 |
| population_total | 總人口數 |
| population_male | 男性人口數 |
| population_female | 女性人口數 |

原始報表中的里數、鄰數，可依分析需求另外保留；「現有門牌」與「戶籍登記」欄位須分開，不能混用。

## 網頁功能

### 互動篩選

- 月份：選擇單一月份或月份區間。
- 行政區：選擇全市、單一行政區或多個行政區。

### 統計指標

- 選定月份及行政區的總人口數。
- 男性與女性人口數及比例。
- 總戶數。
- 平均每戶人口數。
- 與前一月份相比的人口增減數。

### 圖表

| 圖表 | 分析內容 |
|---|---|
| 人口趨勢折線圖 | 觀察各月份人口變化 |
| 行政區人口長條圖 | 比較同一月份各行政區人口數 |
| 男女比例圖 | 觀察選定月份與行政區的男女比例 |
| 戶數趨勢折線圖 | 觀察各月份戶數變化 |
| 資料明細表 | 顯示篩選後的數值，提供 CSV 下載 |

## 計算方式

- 男性比例＝男性人口數 ÷ 總人口數 × 100%。
- 女性比例＝女性人口數 ÷ 總人口數 × 100%。
- 平均每戶人口＝總人口數 ÷ 戶數。
- 每月人口增減＝當月人口數 − 前月人口數。
- 每月人口增減率＝（當月人口數 − 前月人口數）÷ 前月人口數 × 100%。

## 資料驗證

- 每個有效月份應包含 12 個行政區。
- 同一個「年月 × 行政區」不能重複。
- 各行政區的男性人口數＋女性人口數，應等於總人口數。
- 12 個行政區的人口數及戶數加總，應與原始報表的「總計」一致。
- 缺少資料的月份不產生數值紀錄，不能填成 0。

## 使用前請注意

- 原始檔包含 1–12 月工作表，但目前僅 1–9 月有數值，10–12 月為空白。
- 本資料為戶籍人口統計，不等同於實際居住人口。
- 各月份人口數是不同時間點的統計，不能相加當作全年人口數。
- 原始報表的「總計」只用於驗證；計算全市人口時，應加總 12 個行政區，避免重複計算。
- 第一個月份若沒有前月資料，人口增減應顯示「無前月資料」。
- 本資料未包含年齡、出生、死亡或遷徙欄位，因此無法直接分析人口老化或人口增減原因。
